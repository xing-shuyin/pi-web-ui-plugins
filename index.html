按 phase 归组渲染模型回答：中间旁白、思考与工具调用收进一个可展开分组，生成时显示工作中，完成后显示用时并自动折叠，只留最终答案平铺。
来源: onjim/codex-messages
⚡ 额度与成本
会话级多模型账本：按 API 提供商和模型连续累计成本、显示 token 与有效单价；订阅明确不计费。
来源: xieweimo/pi-web-ui-contrib/plugins/codex-usage
📄 聊天归档
本地持久聊天归档：保留压缩前原文、按分支浏览历史、问题跳转与 Markdown 文件查看；不调用模型，不修改原会话。
来源: engharat/pi-web-ui-md-chat
⏱️ 模型调度
按时段配置主 bot 与子 bot 的模型/思考档位：可视化编辑时间窗（时区可搜索选择 + 本地时间预览）、可折叠窗口卡、当前生效窗口高亮、永不生效窗口告警与未保存修改保护，写入 ~/.pi/agent/model-schedule.jsonc，保存即生效。
来源: changeworldBT/pi-web-ui-local-patches/plugins/model-schedule
💬 Photon iMessage
Photon iMessage 通道：经本机 Photon sidecar（spectrum-ts gRPC 桥）在 Linux/macOS 上收发 iMessage，零公网 IP。机器人循环、输入动效、用户白名单、多轮会话隔离、/sessions 投票气泡切会话、斜杠命令与 AI photon 工具一应俱全。
来源: changeworldBT/pi-web-photon/plugin
🌿 multi-git
多仓库 Git 总览：工作区内每个仓库的变更、差异、历史、分支、贮藏、跨仓搜索与时间线，另有工作区分支聚合、Fetch/Pull 与内置终端（其余只读）。
来源: EinErste/pi-web-multigit
🌐 代理健康
探测可配置的 HTTPS 目标及代理链路；无代理时检测直连，失败时对比第二目标，谨慎提示网络问题。
来源: xieweimo/pi-web-ui-contrib/plugins/proxy-health
🔄 重连
断连恢复：查看网页服务与重启守护状态，一键重新连接或重启网页服务（支持单服务/全服务重启，配套可选独立守护进程）。
来源: xieweimo/pi-web-ui-contrib/plugins/reconnect
🗄️ 会话归档
左栏会话行内的「收起」按钮：把对话从侧边栏收起来，不删文件、不申请目录授权，也不保存副本（要看历史全文请配 md-chat 之类阅读器）。可设 1/7/30 天或永不到期；到期默认只提醒，手动确认才删文件。附管理面板：恢复（自动展开所在项目、滚动并闪烁定位）与最近删除记录。
来源: FlameFires/pi-web-ui-session-archive
📊 用量账本
记录 pi-web-ui 自己的每一次模型调用：按模型统计调用数、TTFT、延迟、吞吐、缓存命中率、token 与成本，可查看逐条记录、按模型筛选并导出 CSV。成本优先用 SDK 记录，网关不回填时按公开价格表估算并分开展示；数据只来自本机会话与运行事件，不上传任何内容。
来源: JSJ189/usage-ledger
